# Scoring benchmark report

## Scope and method

`v21-benchmarks.test.ts` generates six fictional profiles across student, internship, entry, experienced, senior and career-switcher levels, using engineering, data, business, finance, marketing and healthcare source terms from `domain-resumes.json`. Names/email use Example/example.com. Fixtures are engineered labels, not independent reviewer judgments.

Measures: exact name/email extraction, explicitly expected skill recall, demonstrated-evidence precision, required-job coverage, repeated numeric scores, line-ending invariance, section-order deltas, and evidence versus keyword-only scores. `v21-evidence-measurements.json` includes positive, mention-only, negated, aspirational and absent-skill controls. Missing evidence does not establish missing competence.

## Actual results and evidence

Machine-readable results: `v21-scoring-measurements.json` and `v21-evidence-measurements.json`, regenerated by `npm test`. Assertions require all 12 engineered name/email fields and all 13 explicit skill labels to be detected; repeated scores and line-ending alignment remain stable. Keyword-only skill scores are capped at 30/100; adding practical evidence must not lower that dimension. Section-order deltas are recorded explicitly, not silently normalized. After fixing false location detection, all six tested reorder deltas are zero. All expected section precision/recall values and the 13 labeled-skill precision/recall values are 1.0 on these small engineered fixtures only. The five evidence controls have no demonstrated-evidence false positives or false negatives.

Fixed a concrete false-positive mechanism: negated/aspirational action phrases no longer receive demonstrated evidence credit. Added legitimate action verbs such as architected and spearheaded. Removed the unsupported 2.4x interview-rate claim. Replaced an old arbitrary senior-fixture grade requirement with an evidence-removal sensitivity test.

## Limits and independent rubric

Independent calibration is **pending**. This small English dataset does not measure industry-wide precision, fairness, hiring probability or ATS compatibility. Name/email success is not comprehensive experience/date parsing accuracy. Same-line action matching still mistakes some hypothetical or unrelated contexts; negation filtering may reject valid phrases such as “not only.”

For independent evaluation, two reviewers should separately label: exact source fields and section spans; each required/preferred job skill; mention versus practical evidence with source spans; content clarity, relevance, readability and evidence strength on separately anchored ordinal scales. Resolve disagreements while retaining originals, report inter-rater agreement, and reserve held-out profiles. Do not assign made-up reviewer scores to these fixtures. Expand multilingual and sector-specific examples before changing weights based on benchmark results.

## Additional observed regressions

Expanded employment fixtures revealed a healthcare role/employer swap and a skills list misidentified as header location after reordering. Both were corrected and covered by explicit regressions; accented candidate names now retain Unicode letters. Final benchmark JSON records the resulting fields and dimension deltas.

Saved V2 scores are not retroactively recalculated. Re-analyze historical resumes with the current rubric before comparing scores; persisted history does not yet carry an explicit rubric-version field.
